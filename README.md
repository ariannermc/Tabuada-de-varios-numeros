# Tabuada de vários números
>Um programa em Java que gera a tabuada do 2 até a tabuada do 10 de uma única vez sem entrada do usuário

---

## Funcionalidades
 
- Exibe as tabuadas do 2 ao 10 automaticamente
- Cada tabuada vai do 1 ao 10
- Execução instantânea sem precisar da entrada do usuário

---

## Como usar

**Pré-requisitos:** Java 8 deve estar instalado. </br>
Verifique com:
```
java -version
```

**Passos:**
1. Clone o repositório:
```bash
git clone https://github.com/ariannermc/Tabuada-de-varios-numeros.git
cd Tabuada-de-varios-numeros
```
 
2. Compile o arquivo:
```bash
javac Tabuada.java
```
 
3. Execute o programa:
```bash
java Tabuada
```
